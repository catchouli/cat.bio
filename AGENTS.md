# Notes for AI agents working on this repo

## This is a public repo

Everything here (files, history, commit messages, PR titles and descriptions, issues) is public on GitHub and stays public: deleting something later doesn't take it back. **Under no circumstances put private information in this repo.**

That means none of:

- **Plans, to-dos, reviews or notes about the owner's career**: job searches, applications, timelines, what to say to whom. Keep them in the owner's private notes, outside this repo.
- **Work details** beyond what the published CV and site already say: internal project or product names, colleagues' names, customers, metrics, code or anything else from an employer.
- **Personal details**: phone numbers, home address, family and household, health, money.
- **Names of private repos** (the code stats page checks for this when it's built).
- **Local paths, hostnames, usernames, tokens or keys.**

If a task needs any of that (a site or CV change built on private notes, say), keep the notes elsewhere and commit only the finished public text. If you aren't sure whether something is OK to publish, ask the owner before committing it.

The CV in `cv/` is deliberately public, but only what's already in it. New CV content is the owner's call: ask before adding employer details.

Before every commit, read the full diff and the commit message with this in mind.
