    How this was counted

    Blame, not commits

    Every source file was run through git blame -w, and only non-blank lines attributed to one of Cat's commit identities count. Deleted and rewritten code doesn't add to either total.

    The two eras

    By hand: each repo as it stood at its last commit before 1 August 2026, when Cat started committing AI-written code. With AI: each repo as it stands now, counting only lines committed since then.

    Other people's code left out

    Vendored libraries (SDL, Boost, glm, FreeImage, imgui, Bootstrap, jQuery, Farseer Physics, phpBB's theme and more), generated files such as SWIG wrappers, and files carrying someone else's copyright or licence header are excluded, even when Cat committed them.

    Counted once

    Identical files in several repos count once, and so do near-copies: the same file path in another repo at a similar size. Private repositories are counted but not named. Code that never reached GitHub, like most of Cat's day jobs, isn't here.
