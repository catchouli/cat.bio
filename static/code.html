    How this was counted

    Blame, not commits

    Each repo was checked out at its last commit before 1 August 2026, and every source file was run through git blame -w. Only non-blank lines attributed to one of Cat's 16 commit identities count, so deleted and rewritten code doesn't inflate the total.

    Other people's code left out

    Vendored libraries (SDL, Boost, glm, FreeImage, imgui, Bootstrap, jQuery, Farseer Physics, phpBB's theme and more), generated files such as SWIG wrappers, and files carrying someone else's copyright or licence header are excluded, even when Cat committed them.

    Counted once

    Identical files in several repos count once, and so do near-copies: the same file path in another repo at a similar size, like Stellar Swing Classic inside the remaster or dreamfield's engine and template.

    What's in scope

    The default branch of every repo on catchouli, Pillowdrift, Catchouli-old, Catchouli-Libraries and talkhaus. Work code that never reached GitHub, like most of 2024, isn't here.
